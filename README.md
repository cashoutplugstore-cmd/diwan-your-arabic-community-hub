# Diwan: Your Arabic Community Hub

Project Name: Diwan | ديوان

Build a production-ready modern Arabic social chat platform inspired by Discord, Telegram, and modern communities.

Requirements:
- React 19 + Vite + TypeScript
- Tailwind CSS
- shadcn/ui
- React Router
- Supabase
- React Hook Form
- Zod
- TanStack Query
- Lucide React

Architecture:
- Mobile First
- Responsive
- RTL by default
- Arabic default language with English ready (i18n)
- Dark/Light mode
- Glassmorphism UI
- Smooth animations
- Accessible
- SEO ready
- Component-based scalable architecture

Create folders:
src/components, layouts, pages, hooks, services, lib, types, utils, assets, styles, contexts, supabase.

Pages: Home, Login, Register, Chat, Rooms, Friends, Profile, Settings, Notifications, Search, Admin Dashboard, 404.

Layouts: Responsive Navbar, Sidebar, Mobile Bottom Navigation, Footer.

Reusable UI: Buttons, Cards, Dialogs, Dropdowns, Forms, Inputs, Avatars, Badges, Toasts, Loading Skeletons, Empty States.

Prepare architecture for future features: realtime chat, private messaging, friends, communities, voice rooms, video calls, AI assistant, push notifications, premium membership, ads integration.

Do not generate only mock screens. Produce production-ready architecture, reusable components, routing, authentication foundation, Supabase integration scaffolding, and clean best-practice code.
